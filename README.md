# Jogo da Velha em C#

Jogo de terminal implementado em C# para a disciplina de Estrutura de Dados I.

O jogo usa uma matriz para representar o tabuleiro e alterna os turnos. A lógica está em [Program.cs](Program.cs).

Autores: Bruno Roberto Cataneo e Alexandre da Silva Rocha.

## Executar

Com o SDK do .NET 9 instalado, execute na raiz do repositório:

```bash
dotnet run --project JogoDaVelha.csproj
```
